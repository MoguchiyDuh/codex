# Data Structures

Concrete representations behind the standard ADTs. Organised from foundations to specialised structures. See [[ROADMAP]] for the phased course plan (MIT 6.006).

## Foundations

- [[Abstract Data Types]] — interface vs implementation, sequence vs set
- [[Arrays]] — static, dynamic, amortized growth, memory layout
- [[Linked List]] — singly, doubly, circular, sentinel
- [[Stack & Queue]] — LIFO, FIFO, deque, ring buffer

## Hierarchical and priority

- [[Trees]] — terminology, binary trees, traversals
- [[Binary Search Tree]] — ordered keys, in-order = sorted, degeneration
- [[AVL Tree]] — strictly balanced BST via rotations
- [[Red-Black Tree]] — loosely balanced BST used in standard libraries
- [[B-Tree]] — high-fanout tree for disk and database indexes
- [[Heap]] — priority queue backed by a complete binary tree

## Hashing

- [[Hash Tables]] — hash functions, chaining, open addressing, load factor
- [[Bloom Filter]] — probabilistic set membership

## Graphs

- [[Graphs]] — adjacency lists, matrices, edge lists, sparse-vs-dense tradeoffs
- [[Disjoint Set]] — union-find with path compression and union by rank
